Gemini Decision 1 API pricing — $0.10 input, $0 output, billed once per request

Google's decision endpoint (launched Nov 11, 2026) prices the gemini-decision-1 model at $0.10 per MTok of input and nothing at all for output — because it doesn't generate text. It scores up to 1,000 yes/no, choice and rubric questions over one shared multimodal input in a single pass at 150-250 ms, and your input is billed once per request regardless of how many questions you ask. All rates below are from Google's published announcement.

What one request actually bills

Decision 1's bill has exactly one moving part: the shared input. A representative moderation request — a 2,000-token context (say, a screenshot plus a text note) with five yes/no and rubric questions at ~100 instruction tokens each — bills 2,500 input tokens, i.e. $0.00025 per request, or $0.25 per 1,000 requests. Add a sixth question and the bill moves by that question's ~100 tokens, not by a second forward pass over the whole context.

The fine print that changes the picture

  • The output isn't text. You get per-question probabilities and normalized choice distributions with confidence scores — your code routes low-confidence cases to a fallback or human. If the deliverable is prose, this endpoint can't produce it.
  • 256K-token input cap, but the latency claim is 16K. The shared input accepts up to 256K tokens across modalities; Google's flat-latency figures are measured on contexts up to 16K tokens, so expect compute to grow somewhere between those bounds on very large inputs.
  • Three question shapes, one pass. Yes/no (with optional true/false criteria), multiple choice over 2-255 candidates, and ordered rubric scoring from 0 up — mixable in a single request against the same input.
  • Compared pricing is official, not ours. Google's own claim: nearly 5x cheaper across the shared benchmark suite than Gemini 3.5 Flash-Lite answering through the Interactions API — the savings come from billing input once and never billing output.

What Google built it for

The launch post's worked examples are all control-plane jobs: Gemini Notebook routes queries to the right model tier in milliseconds (up to 40% lower latency on everyday queries), Stitch's rapid canvas turns voice edits into playable wireframes in seconds, Google Labs' CC picks emoji reactions from a 200-plus palette without adding latency, and Google Search uses it as a safety layer for MCP tool calls. That's the template for your own usage: a low-latency router or grader in front of bigger models — not a replacement for them. FAQ

How much does Gemini Decision 1 cost?

$0.10 per million input tokens, $0 output (model ID gemini-decision-1), verified Nov 12, 2026 against Google's Nov 11 announcement. The shared input bills once per request no matter how many questions you evaluate; each question adds only its own instruction and criteria tokens. No thinking-token, audio-transcription or OCR charges, and a no-cost tier runs in Google AI Studio.

What is the Gemini Decisions API?

A closed-set decision endpoint: one multimodal input (text, images, audio, video, PDFs, up to 256K tokens) plus up to 1,000 yes/no, multiple-choice (2-255) or ordered-rubric questions, scored in a single forward pass with probabilities and 0-1 confidence scores at 150-250 ms end-to-end. Google benchmarks it at nearly 5x cheaper than Gemini 3.5 Flash-Lite via the Interactions API on the shared suite.

Does Gemini Decision 1 have a free tier?

Yes — a no-cost API tier is available in Google AI Studio for prototyping. Paid usage starts at $0.10/MTok input with nothing billed for output.

Gemini Decision 1 vs Claude Haiku 5.5 for classification — which is cheaper?

Input ties at $0.10/MTok; output is the difference. Decision 1 bills $0 (probabilities only), Haiku 5.5 bills generated text at $0.50/MTok. On 100K requests/day with ~150 generated tokens each, that's roughly ~$750 vs ~$975 a month. Decision 1 only handles bounded choices — anything needing written answers stays with Haiku 5.5 or another generative model.

What are Gemini Decision 1's limits?

256K-token multimodal input cap per request (Google's flat-latency claim is measured up to 16K-token contexts), 2-255 multiple-choice options, rubrics ordered from 0, and probability-only output — no prose. Batch and priority tiers weren't published at launch; Gemini-on-Google-Cloud support is "coming soon."
