The real math: API vs Pro vs Max, three worked examples

All three examples use Sonnet 5.5 at $2 per million input and $10 per million output tokens, billed over 30 days.

1 · Light chat — 60K input, 6K output per day

Daily cost: (0.06M × $2) + (0.006M × $10) = $0.18 → about $5.40/month. The $20 Pro plan wins outright, and you get claude.ai, Projects, Claude Code and the desktop app on top. Nobody should pay API rates for pure chat.

2 · Daily Claude Code — 800K input, 80K output per day

Daily cost: (0.8M × $2) + (0.08M × $10) = $2.40 → about $72/month. Pro's $20 is far cheaper if your usage fits inside the 5-hour and weekly caps. Heavy Claude Code users routinely burn a Pro window in a morning — that's exactly who Max 5x ($100) targets: still flat-rate, ~4× the token budget of this example.

3 · Agent / automation — 6M input, 600K output per day

Daily cost: (6M × $2) + (0.6M × $10) = $18 → about $540/month. Max 20x ($200) is nominally cheaper but its caps assume interactive rhythms, not 24/7 runs — unattended agents blow through weekly limits in days. At this volume the API is the only honest answer, and prompt caching is the next lever: a cached-heavy pipeline at $0.10/MTok input drops the input line from $360 to $18 a month.

The breakeven, in one sentence

On Sonnet 5.5 with a typical 10:1 input/output mix, the API overtakes Pro at roughly 220K input tokens per day (~22K output), and it overtakes Max 5x near 1.1M input per day. The calculator above computes this for your exact mix and model — the sliders are the model.

Which should you pick?

  • Pick Pro ($20) if you use Claude interactively a few hours a day and can live inside the windows. It's the cheapest tokens on the market, period.
  • Pick Max 5x / 20x if you love flat pricing but keep hitting weekly caps — you're buying headroom, not different economics.
  • Pick the API if any of these are true: your workload runs unattended or overnight; you need zero rate limits; you already have (or want) programmatic access; or caching covers most of your input. Above the breakeven, every extra token is the same price — predictability beats caps.
  • Hybrid: many teams run Claude Code on a Max seat for interactive work and shift batch jobs to the API with Haiku 5.5 or cached Sonnet — the calculator's preset slider shows both bills at once.

Frequently asked questions

Is the Claude API cheaper than a Claude Pro subscription?
It depends on volume. On Sonnet 5.5 pricing ($2/M input, $10/M output), the API breaks even with $20 Pro at roughly 220K input and 22K output tokens per day. Below that, Pro wins; above it, API costs scale linearly while Pro stays flat until you hit the 5-hour and weekly caps.
How much does the Claude API cost per million tokens?
October 2026 rates: Opus 5.5 $4 in / $20 out; Opus 5 $5/$25; Sonnet 5.5 and Sonnet 5 $2/$10; Haiku 4.5 $1/$5; Haiku 5.5 $0.10/$0.50. Cached input runs from $0.01/MTok (Haiku 5.5) to $0.50/MTok (Opus 5).
What are Claude's subscription plans in 2026?
Free $0; Pro $20/month ($17 monthly-billed annually); Max 5x $100; Max 20x $200; Team $20–25/seat standard and $100–125 premium. All paid plans share one usage pool across web, desktop, mobile and Claude Code, measured in rolling 5-hour windows plus weekly limits.
Do Claude Max plans include API credits?
Max raises caps and adds peak-time priority. Once you hit limits you can enable extra usage billed at standard API rates, and Team plans can pool up to $500/month of API credits — but a Max subscription is not unrestricted API access.
How do Claude's 5-hour limits work?
Usage resets in rolling 5-hour session windows, with weekly limits stacked on top for paid plans. Chat, desktop, mobile and Claude Code all draw the same pool. A heavy Claude Code session can drain a Pro window in under an hour.
When does the Claude API win vs a subscription?
Unattended automation, 24/7 agents, high daily volume, caching-heavy pipelines, and anything that can't tolerate rate limits. If your work fits in interactive windows, the subscription's flat rate is unbeatable.
Did Claude API prices change recently?
Yes — Opus 5.5 launched at $4/$20, about 20% below Opus 5's $5/$25, and Sonnet 5.5 introduced a $0.10 cached-input tier. The trend across 2026 has been flagship prices drifting down while subscription caps tighten.
