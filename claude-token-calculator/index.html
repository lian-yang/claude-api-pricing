Frequently asked questions

How much does one Claude API token cost?
Prices are per million tokens: Opus 5.5 $4 in / $20 out (that's $0.000004 per input token, $0.00002 per output token); Sonnet 5.5 $2/$10; Haiku 4.5 $1/$5; Haiku 5.5 $0.10/$0.50.
How many tokens are in a word?
About 1.33 tokens per English word (~0.75 words per token, ~4 characters per token). Code, non-Latin scripts and dense punctuation can double that. 500 words ≈ 670 tokens; 100-page PDF ≈ 50K–80K tokens.
How do I calculate a request's cost?
input_tokens × input_price + output_tokens × output_price, both priced per million. 10K-token prompt + 2K-token answer on Sonnet 5.5 = 0.01×$2 + 0.002×$10 = $0.04. The calculator above does this for every model at once.
Does caching change per-token pricing?
Cached input runs $0.20/MTok on Opus 5.5, $0.10 on Sonnet 5.5, $0.01 on Haiku 5.5 — 90%+ cheaper than uncached input when cache hits land. Repeated system prompts are the classic win.
How many tokens fit in Claude's context window?
Current-gen models expose 1M-token windows (Opus 5.5, Sonnet 5.5, Haiku 5.5); Sonnet 4.x and Haiku 4.5 are 200K. On Argon-style shared windows, thinking tokens count against the same budget — see the Argon rate card for that model's split.
