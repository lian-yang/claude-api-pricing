Voxtral API pricing — per-minute transcription, TTS and voice-agent rates

Mistral's Voxtral 3 wave bills speech by the minute: $0.0035/min for batch transcription on Mini Transcribe 3, $0.0040/min for the accuracy-flagship Small model, $0.008/min realtime, $13 per 1M characters for TTS, and $0.04–0.08/min for the full voice-agent stack. Every rate below is from Mistral's own announcement page.

What a minute of audio actually costs

Per-minute pricing makes budgets arithmetic. One hour of recorded audio is $0.21 with batch Mini Transcribe 3, $0.24 on Small Transcribe 3, and $0.48 if you need realtime. A podcast archive of 100 hours runs about $21 to transcribe in full. The voice-agent figures stack differently — $0.04/min is $2.40 per hour of live conversation including the reasoning model, which is the number to compare against human agent costs, not against other transcription APIs.

Per-minute now, per-token last generation

Naming trap worth dodging: the Transcribe 3 models above are billed per minute and are the current API. The earlier open-weights line — Voxtral Small 24B 2507 and its siblings — is billed per audio token and still shows up on aggregators like OpenRouter at $0.10 input / $0.30 output per million tokens. Same family name, different product and different billing model. If a pricing page quotes per-token Voxtral rates, it's describing the 2507 generation, not the current API.

Where Voxtral fits next to Claude

Claude has no speech input or output — the common production pattern is Voxtral for the ears, Claude for the brain. A 10-minute meeting costs $0.035 to transcribe with batch Mini; handing the ~1,500-word transcript to Claude Haiku 5.5 ($0.10/$0.50 per MTok) for a summary costs a fraction of a cent. Even the voice-agent route stays cheap: at $0.04/min with Mistral Small 4 doing the reasoning, an hour of automated phone support runs $2.40 before you add a Claude or Opus-class escalation path. FAQ

How much does the Voxtral API cost?

Verified Oct 23, 2026: Mini Transcribe 3 batch $0.0035/min; Small Transcribe 3 $0.0040/min; Mini Transcribe Realtime 3 $0.008/min; Mini TTS 3 $13 per 1M characters; voice-agent API $0.04/min with Mistral Small 4 reasoning or $0.08/min with a larger model.

Is there a free tier for Voxtral?

No free API tier is documented as of Oct 23, 2026 — it's pay-as-you-go from the first minute. Mistral's Studio playground lets you test the models without writing code, and the consumer Vibe/Pro plans cover Mistral's chat products, not API audio usage.

Can I use Voxtral with Claude?

Yes — Voxtral transcribes, Claude reasons. A 10-minute meeting is $0.035 on batch Mini; a Claude Haiku 5.5 summary of the transcript costs well under a cent. The two APIs never talk directly; your code passes the transcript as a prompt.

Why do some Voxtral prices show up per token?

Those are the older open-weights models (Voxtral Small 24B 2507 at $0.10/$0.30 per million audio tokens on OpenRouter, for example). The current Transcribe 3 generation is per-minute. Check which generation a price refers to before comparing.

What about self-hosting Voxtral?

The older Voxtral releases shipped open weights you can run yourself; the current full stack (Transcribe 3, TTS 3, voice-agent SDK) is available on Mistral's hosted endpoints, with on-premises and private-cloud deployment offered as an enterprise arrangement.
