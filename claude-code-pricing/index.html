Claude Code pricing — what it really costs per month

There is no separate Claude Code subscription. It rides on your Claude plan: $20 Pro, $100 Max 5x, or $200 Max 20x — or you can skip plans entirely and bill an API key per token. Here's what each route costs in practice.

What "5-hour windows + weekly caps" means for your bill

Subscription usage resets in rolling 5-hour session windows, with weekly limits stacked on top. Claude Code is the heaviest consumer in that pool: it re-reads project context every turn, so real coding sessions run about 10:1 input-to-output. A focused morning of Claude Code can drain a Pro window; Max multipliers exist precisely to buy headroom for this.

Three worked Claude Code budgets

  • Light coding — 100K input, 10K output per day (Sonnet 5.5): (0.1M×$2)+(0.01M×$10) = $0.30/day ≈ $9/month on API. The $20 Pro plan is the wrong choice on pure cost — but Pro includes claude.ai, Projects and mobile, which is why most people take it anyway.
  • Daily driver — 800K input, 80K output per day (Sonnet 5.5): $2.40/day ≈ $72/month on API vs $20 Pro — if your usage fits the windows. If it doesn't, the realistic flat-rate option is Max 5x at $100.
  • Professional / near-continuous — 4M input, 400K output per day (Sonnet 5.5): ≈ $360/month on API, vs Max 20x at $200 if an interactive rhythm fits. Around-the-clock automation on Max caps fails weekly limits — this is API-key territory, where prompt caching (input at $0.10/MTok) can pull the bill back under $100.

When to bill Claude Code through the API instead

  • Unattended or scheduled runs — cron jobs, CI checks, overnight refactors that can't pause when a window closes.
  • Volume past Max 20x economics — once monthly API-equivalent cost is comparable to $200, predictability per token beats caps you still have to schedule around.
  • Caching-heavy workflows — big stable system prompts + CLAUDE.md hit cached-input rates and slash the input line.
  • Model choice per task — the API lets you route routine edits to Haiku 5.5 ($0.10/$0.50) and reserve Opus 5.5 for hard problems; on plans, you'd switch models manually.

Frequently asked questions

How much does Claude Code cost?
It's included in every paid Claude plan — Pro $20/mo, Max 5x $100/mo, Max 20x $200/mo — with no separate Claude Code fee. Alternatively, point Claude Code at an API key and pay per token with no caps (Sonnet 5.5: $2/$10 per million tokens).
Is Claude Code included in the $20 Pro plan?
Yes, alongside claude.ai, desktop and mobile — all sharing one usage pool in rolling 5-hour windows plus weekly caps. Light-to-medium daily coding fits; sustained all-day sessions can exhaust a Pro window in a morning.
How much is Claude Code on Max?
Max 5x is $100/month, Max 20x is $200/month. You're buying headroom per 5-hour window and peak-time priority — the Claude Code features are identical to Pro's.
Can Claude Code use an API key instead of a subscription?
Yes. API-key mode bills per token with no usage caps — at the standard API rates listed above. It's the right mode for automation and CI; interactive daily coding is almost always cheaper on a plan.
Why does Claude Code use so many tokens?
It re-reads project context each turn, so coding runs roughly 10:1 input-to-output. Concise CLAUDE.md files, prompt caching, and delegating routine edits to Haiku 5.5 or Sonnet 5.5 all stretch a window further.
Do Team plans include Claude Code?
Yes — Team seats ($20–25/seat/month standard) include Claude Code, with usage drawn from the pooled allowance and billable overage at API rates. Enterprise adds custom annual pricing.
