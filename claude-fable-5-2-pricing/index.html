Claude Fable 5.2 API pricing — $8/$40 per MTok, batch, cache and Fast rates

Anthropic's new flagship (released Nov 9, 2026) is also the first Fable to get a price cut: $8 in / $40 out per MTok, 20% below Fable 5.1. Batch runs half price, cache reads are $0.20, and Mythos 5.2 shares every number behind a verification gate. All rates below are from Anthropic's published docs and price list.

The fine print that changes architectures

  • 30-day retention, no ZDR. Fable 5.2 "requires 30-day data retention and isn't available under zero data retention unless expressly authorized by Anthropic" — a hard gate for healthcare, finance and legal pipelines built on ZDR assumptions.
  • No forced tool use. tool_choice types any and tool return a 400 error — orchestration frameworks that force tool calls need a fallback path.
  • Sampling params are out. Sending temperature, top_p or top_k errors on this model; strip them from request templates.
  • Thinking is always billed. Adaptive extended thinking can't be disabled — the effort parameter is your only cost dial.

Mythos 5.2: same model, gated front door

Claude Mythos 5.2 shares Fable 5.2's specifications and pricing — $8/$40, same batch and cache lines — but it is not self-serve. Access is restricted to organizations verified through Anthropic's verification programs, such as the Cyber Verification Program; you apply to the covering program or go through your account team. Everyone else calls the same model as claude-fable-5-2. If a vendor advertises "Mythos 5.2 API access" at retail, that's a reseller front, not a separate model.

Subscriptions: when you don't pay these rates at all

On the consumer side, Anthropic's support article for Fable models on plans (published for Fable 5/5.1) includes Fable usage at up to 50% of weekly usage limits on Max plans and premium Team/Enterprise seats — check the current article for 5.2's exact terms. Separately from inclusion, Max ($100/mo) now ships with $100/month in API credits and Ultra ($200/mo) with $200/month, so heavy users effectively rebate their first tranche of API spend at standard rates — see the API vs subscription calculator for the breakeven math.

FAQ

How much does Claude Fable 5.2 cost?

$8 per million input tokens, $40 per million output (model ID claude-fable-5-2), verified Nov 10, 2026 against Anthropic's docs. Batch API is half price at $4/$20; cache reads $0.20/MTok; cache writes $10 (5-minute) and $16 (1-hour); the Fast service tier doubles everything to $16/$80.

Is Fable 5.2 cheaper than Fable 5.1?

Yes — 20% cheaper on both sides: $8/$40 vs $10/$50, with cache reads down from $0.25 to $0.20. It's the first Fable base-price cut, and Anthropic claims up to 30% faster output than 5.1, so the cost per finished task drops from both directions. Fable 5.1 remains listed at its old rates while 5.2 takes the "latest" alias.

Fable 5.2 vs Opus 5.5 — which should I use?

Opus 5.5 ($4/$20) is Anthropic's own recommendation for most coding and knowledge work — exactly half Fable 5.2's price. Pay the Fable premium when a task stalls Opus: long-horizon agent sessions, deep research carried through to a finished deliverable, the hardest migrations. Third-party benchmarks put Fable 5.2 clearly ahead (AA Intelligence Index 64.6 vs 59.1; HLE 74.3% vs lower ranks) — the question is whether that gap is worth 2× on your traffic, which only your task mix answers.

What is Claude Mythos 5.2?

The same model as Fable 5.2 — identical specs and pricing — restricted to organizations verified through Anthropic's verification programs (e.g., Cyber Verification). Not self-serve; apply via the program or your account team.

Does Fable 5.2 work with zero data retention?

No. It requires 30-day data retention; ZDR is only available if Anthropic expressly authorizes it. ZDR-dependent pipelines need that authorization in hand before adopting this model.

Why is my Fable 5.2 bill higher than the list-price math?

Thinking is always on (default high effort) and reasoning tokens bill as output at $40/MTok. Lower the effort parameter for routine steps, make prompts cache-friendly ($0.20 reads; real-world realized input averaged ~$1.03/MTok at ~92% cache hit on launch day), and push async work through Batch at 50% off.
