DeepSeek Search & Fetch API pricing — $0.75 per 1,000 requests

DeepSeek's new Search and Fetch APIs bill $0.75 per 1,000 successful requests each — failed requests cost nothing. Tool calls inside Claude Code are free until Nov 1, 2026, then billed at the same rate. That list price undercuts Tavily by ~10x and Serper's starter tier by 25%.

Billing is per request — not per token and not per result: raising count (results per search, up to 50) doesn't change the price. Failed requests, empty searches and timeouts are never billed. Charges come off your DeepSeek balance; granted balance is spent before topped-up balance.

The Nov 1 deadline: free tool calls are ending

Right now, search and fetch made as server-side tool calls — through DeepSeek Harness, Claude Code, or Codex — cost nothing. That window closes at 00:00 Beijing time on November 1, 2026, when the same $0.75/1,000 rate kicks in. Two practical notes: first, if your agents lean on Claude Code's built-in web tools against a DeepSeek backend, budget for search volume from Nov 1; second, calling the standalone endpoints directly (/v1/tools/search, /v1/tools/fetch) has been billed per request since launch, so the deadline only matters for the server-side path.

What the gap is worth at 10k searches/day

At a busy agent workload of 10,000 searches a day (~300k/month): DeepSeek runs $7.50/day ≈ $225/mo. Serper's starter tier costs $300/mo — and hits exact parity ($225) only once you're on the 500k-credit Standard tier. Exa lite is $1,200/mo, Brave Search $1,500/mo, Tavily pay-as-you-go $2,400/mo. Tavily's generous free tier (1,000 credits/month) and Serper's 2,500 free queries are rounding errors at this volume.

Billing mechanics worth knowing

The "successful request" bar is the notable part of the pricing: a Search call bills only when it returns HTTP 200 with a non-empty results array, and Fetch only when it returns actual page content. Rate limits are per account, not per key — separate from model concurrency — and Fetch adds a per-domain QPS limit on top of its 25 QPS. Exceeding either returns 429. Retry on 408/429/5xx, top up on 402, and don't retry other 4xx unchanged; on Fetch, 403 means a security-policy rejection and 404 means no usable content (blocked or empty page).

What $0.75/1k actually buys

Search queries are 1–128 characters, return up to 50 results, and support real query operators: site:, -site:, -term, "exact phrase", lang:, after:/before: date filters. Each result ships with a rerank score (0–3; ≥1.5 = high quality), an authority score (0–4; ≥3 = highly authoritative), snippets, optional ~600–800 character summaries, and RFC 3339 dates — enough metadata to filter results in-agent without a second ranking pass. Fetch takes URLs up to 8,192 characters and returns the title plus clean Markdown, which is what makes it a one-call substitute for "search then scrape".
