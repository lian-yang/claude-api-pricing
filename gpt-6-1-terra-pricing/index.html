GPT-6.1 Terra API pricing — $1/$5 per MTok, batch, cache and Fast rates

OpenAI's value workhorse (launched Oct 27, 2026) prices at $1 in / $5 out per MTok — exactly half of GPT-6.1 Sol — for visual reasoning, precise computer use and natural writing. Batch runs half price again, cache reads are $0.05, and the same rates make it the cheapest big-context tier in the GPT-6 family. All rates below are from OpenAI's published rate card.

The fine print that changes bills

  • Long-context surcharge. Prompts over 272K input tokens price at 2× input/cache and 1.5× output for the entire request — effective $2 in / $7.50 out at 273K+. With a 1.05M window it's easy to cross accidentally; batch's 50% off applies on top and claws much of it back.
  • No realtime. Live and Realtime endpoints are unsupported — voice and streaming-audio pipelines need a different model (e.g., gpt-realtime-2.1).
  • Reasoning is billed as output. The effort dial (none→max) is your cost dial; hidden reasoning tokens land on the $5 output line.
  • Computer use runs through Responses. Terra's headline computer-use skill is only reachable via the Responses API — Chat Completions handles plain text-and-image requests.

What Terra is built for

OpenAI's model doc positions Terra as "a fast, efficient model for visual reasoning, precise computer use, and clear, natural writing" — with the worked examples being matching product photos to catalog entries, interpreting technical drawings, acting on application screens, and drafting/revise text. That's an e-commerce and ops-automation brief, not a frontier-research brief: route the hard agentic coding to Sol or Astra, the 24/7 vision-plus-clicks pipeline to Terra, and pure high-volume classification down to Luna at $0.10/$0.50.

FAQ

How much does GPT-6.1 Terra cost?

$1 per million input tokens, $5 per million output (model ID gpt-6.1-terra), verified Nov 10, 2026 against OpenAI's rate card. Batch/Flex run $0.50/$2.50; cache reads $0.05/MTok; cache writes $1.25 (30-minute) and $2.50 (12-hour); the Fast service tier doubles everything to $2/$10.

How does GPT-6.1 Terra compare with GPT-6.1 Sol?

Terra is exactly half of Sol on every line — $1/$5 vs $2/$10, batch $0.50/$2.50 vs $1/$5, cache $0.05 vs $0.10. Sol keeps the edge on demanding agentic coding; Terra covers visual reasoning, computer use and writing at half price with the same 1.05M-token context and an effort dial from none to max.

GPT-6.1 Terra vs Claude Sonnet 5.5 — which should I use?

Terra is half of Sonnet 5.5 on every published rate ($1/$5 vs $2/$10; cache $0.05 vs $0.10; batch $0.50/$2.50 vs $1/$5). On our standard agent workload that's ~$1,009 vs ~$2,018 per month. Terra's computer use requires OpenAI's Responses API and it has no realtime endpoints; the capability tiebreak is your own prompt set — but on price alone, Terra now undercuts the Claude workhorse line.

What is the long-context surcharge?

Prompts over 272K input tokens bill at 2× input and cache rates and 1.5× output for the full request — effective $2/$7.50 at the margins. Terra's 1,050,000-token window (922K max input) makes it easy to cross; batching (50% off) and keeping prompts under the threshold are the two levers.

Does GPT-6.1 Terra support audio, video or realtime?

No — text and image in, text out. The Live and Realtime endpoints don't support this model, and tool calling requires the Responses API. Voice pipelines need OpenAI's realtime models instead.
