Muse Spark 1.3 API pricing — $1.25/$4.25, or $0.10/$0.20 if Meta may train on it

Meta's Model API prices the whole Muse Spark line at $1.25 input / $4.25 output per million tokens — already 3.2–4.7x under Claude Opus 5.5 — and then cuts the floor out: a Contributor tier at $0.10/$0.20 in exchange for training rights. Here's the full rate card, the catch, and the vs-Claude math.

Contributor mode: the 12.5x/21x discount and its catch

Contributor mode runs the same models at $0.10 input / $0.20 output — a 12.5x input and 21x output cut versus Standard — in exchange for permission to use your content to train future Meta models: the prompts, code, files and context you send, plus everything the model sends back. You opt in per-call by invoking the -contributor variant, so a team can prototype on Contributor and promote production traffic to Standard without changing anything else. Two hard trade-offs beyond the training rights: rate limits drop to 150 RPM / 3M TPM (vs 3,000 RPM / 4M TPM), and anything sensitive — proprietary code, client data, regulated records — should never ride a tier whose payment is your data.

The Contributor tier is the cheapest frontier-class output price on any major API right now — below even DeepSeek's budget Flash line, with a 1M-token window attached. The open-weight Muse Spark Open release (816B MoE, ~42B active) technically undercuts it at $0/token, but self-hosting needs 512GB-class memory or multi-GPU servers at $15–25/hour, so the hosted Contributor rate captures most of the open-weights discount without the hardware.

Billing details the rate card doesn't front-page

  • Flat to full context: the same per-token rate applies whether the window is nearly empty or packed — no long-context surcharge, so a 900K-token prompt bills like a 900-token one.
  • Cached input is the quiet multiplier: $0.15/M Standard (75% off fresh input) and an almost-invisible $0.002/M on Contributor. Agent loops and document Q&A that re-send context should be architected around cache hits.
  • Web search grounding: $2.50 per 1,000 search queries on top of token costs when the web_search tool fires.
  • Steering tokens are free: Meta injects a small system-prompt scaffolding into every request and excludes it from billing and token counts.
  • Team-level limits: 3,000 RPM / 4M TPM per model per team (150 RPM / 3M TPM Contributor); every key in a team shares one pool, but traffic to one model doesn't consume another's budget. Background responses add a 600 submissions/min cap per team — above it you get HTTP 429.
  • Muse Code ≠ Model API: the consumer app/IDE path bills a monthly subscription; the per-token rates here are the developer API only.

Naming traps before you call it

Three things to check before your first bill: there is no bare muse-spark alias — requests target a version (muse-spark-1.3, muse-spark-1.2, muse-spark-1.1), and the API's model list is the source of truth for what's live. The discount is not a parameter — Contributor pricing only applies when you call the -contributor variant (muse-spark-1.3-contributor), which aggregators like OpenRouter mirror under meta/muse-spark-1.3-contributor. And 1.1 has no contributor line — if a config template points 1.1 at a contributor alias, the request fails rather than silently downgrading.

Practical split: run prototypes, batch jobs and retry-tolerant pipelines on Contributor at $0.10/$0.20 as long as the training-rights trade and 150 RPM cap fit — nothing else at this capability level comes close on price. Move production and any sensitive traffic to Standard at $1.25/$4.25, which still beats Sonnet 5.5 by ~1.6x/2.4x with 20x the rate ceiling. Keep Opus 5.5 for the frontier slice — and check the vs-Claude math before routing hard agentic work anywhere.

Frequently asked questions

How much does the Muse Spark 1.3 API cost?
$1.25 input / $4.25 output per million tokens Standard (cached input $0.15), identical for 1.3, 1.2 and 1.1. Contributor variants run $0.10/$0.20 with cached input at $0.002. Verified against Meta's Model API pricing page Oct 23, 2026.
What is Muse Spark Contributor mode?
The same models at ~12.5–21x cheaper rates in exchange for Meta training on your traffic — prompts, code, files and responses. Opt in by calling the -contributor variant; limits drop to 150 RPM / 3M TPM. Keep proprietary or client data on Standard.
Is Muse Spark cheaper than Claude?
At every tier: Standard's $1.25/$4.25 is 3.2x/4.7x under Opus 5.5 ($4/$20) and 1.6x/2.4x under Sonnet 5.5 ($2/$10); Contributor's $0.10/$0.20 is 40x/100x under Opus at list. The 30M+5M daily agent runs $58.75/day Standard vs Opus's $220.
How do Muse Spark's rate limits work?
Per team, not per key, and per model: Standard 3,000 RPM / 4M TPM, Contributor 150 RPM / 3M TPM. Background responses add a 600 submissions/min team cap that returns HTTP 429 when exceeded.
Is there a long-context surcharge?
No — flat per-token rates to a full 1M window, unlike older Qwen tiers that rise up to 4x past 128K. Meta's injected steering context isn't billed or counted.
Can I get Muse Spark 1.3 cheaper than list?
Contributor mode ($0.10/$0.20), the free open weights (realistic only with $15–25/hour of self-host hardware for the 816B MoE), or OpenRouter's contributor listing. Cached input at $0.15 is the only Standard-mode discount.
